What these numbers mean

One contract.
Several implementations.

All backends return squared Euclidean distances and vector IDs, sorted by distance and then ID. Every recorded repeat is checked against an independent direct-distance oracle.

Whole-call timing includes validation and output allocation. The reference is readable NumPy code; it is not a tuned FAISS or BLAS baseline.

CPU measurements do not establish NVIDIA GPU performance. An optional PyTorch CUDA path is included, with hardware validation left explicit.

Under the surface

01

Bound the working set.

NumPy uses two reusable distance tiles. C++ streams one corpus vector at a time into a size-k heap per worker. Neither needs the full query-by-corpus distance matrix.

02

Make edge cases ordinary.

Duplicate vectors, ties across tiles, empty query batches, noncontiguous input, invalid dimensions and numerical overflow have explicit behavior and regression tests.

03

Expose the tradeoffs.

Exact search still costs O(QND). Tiling changes workspace, not that fundamental cost. Performance depends on shape, k, threading, hardware and validation overhead.
